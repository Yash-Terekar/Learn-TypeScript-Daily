# Learn TypeScript Daily 🚀

Welcome to my **Learn TypeScript Daily** repository! This repository documents my journey of learning TypeScript through hands-on practice, coding challenges, and practical examples.

I'm learning TypeScript to write safer, more maintainable JavaScript and prepare for building larger applications using React, the MERN stack, and React Native.

## 🎯 Goals

- Understand TypeScript fundamentals and its type system.
- Learn type inference, type annotations, and built-in types.
- Practice arrays, objects, functions, and typed callbacks.
- Understand `type`, `interface`, union types, and type narrowing.
- Explore generics and asynchronous TypeScript.
- Apply TypeScript to React components, props, state, and events.
- Build a strong foundation for TypeScript-based full-stack development.

## 💻 Running TypeScript Code

Install the project's local tools once:

```bash
npm install
```

Run the introductory example:

```bash
npm start
```

The workspace also configures the Code Runner extension to run `.ts` and
`.tsx` files with `tsx`. Use Code Runner's **Run Code** command or run a file
directly with `npx tsx "path/to/file.ts"`. Code Runner executes the code but
does not type-check it; check TypeScript errors with:

```bash
npm run typecheck
```
